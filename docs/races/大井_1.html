見かた(◎・込%・一言・3連複・AI買い目)
  • ◎○▲△ … AIの1着率の順。AIはオッズ・人気を使わず、過去の成績・タイム・騎手などだけで評価(地方11場のデータで学習)。1番人気以外も普通に◎になる。
  • 込% … オッズ込みの1着率。単勝オッズ(みんなの評価)に、AIが見ている要素のうち市場が織り込み切れていない分を足したもの。オッズが変わると変わる。AIの%はオッズでは変わらない。
  • 妙味 … 込% ÷ オッズから見た確率。1.15以上を「妙味」とする。
  • 一言 … 普通=◎が込%1位と同じ、または2〜3番人気(ほぼオッズどおり。普通に買ってよい) / 注意=◎が込%1位と違う1番人気・4〜5番人気 / 危険！=◎が込%1位と違う6番人気以下 / 推し=注意・危険のレースで代わりに推す馬(込%1位。過去 複勝圏66%・複回90%)。
  • 3連複 … E=込%1位軸→込%2〜4位→3着内率10%以上(的中率67%・回収率77%)。E'=そのうち市場より1.2倍以上来やすい組だけ(的中率16%・回収率90%)。
  • EV … 単勝だけ。込% × 今のオッズ。
  • 地方は市場(オッズ)がよく当たっていて、回収率100%を超える買い方は見つかっていない。AI買い目は「全体の平均(単勝約70%)よりまし」なもの。
